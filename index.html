Install in four steps

  1. Tap “Download for Android.”If Google Drive says it can’t scan the file for viruses, tap “Download anyway.”
  2. Open the downloaded file.
  3. Allow installs from Chrome when Android asks.
  4. Tap Install, then Open.

Questions

Why does Android warn me before installing?

Apps installed outside the Play Store always show this message. Only install the file from this page.

The download didn’t start. What now?

Open this page in Chrome and tap the button again, or use “Open in Google Drive” and tap Download there.
